SSH Log Parser & Security Event Normalizer

A Python automation script that parses raw Linux SSH authentication logs, extracts security-relevant information, and converts the events into structured JSON data.

GitHub Repository ↗ ← Back to Projects

01 // Overview

Linux SSH authentication logs contain useful information about login attempts, including usernames, timestamps, and source IP addresses. However, the raw logs are designed for humans to read rather than for structured security analysis.

I built this project to automate that first step of analysis. The Python script reads the authentication log, identifies failed SSH login attempts, extracts the relevant fields, and writes the results into a structured JSON file.

02 // How It Works

01

Read Logs

02

Filter Events

03

Extract Data

04

04 // Python Implementation

The parser is written in Python and uses basic file handling, string parsing, and JSON serialization to transform the raw log data. 

import json

# 1. Define where our input log file is and where our output JSON will go
log_file_path = "logs\\sample_auth.log"
output_file_path = "output.json"

# 2. Create an empty list to store the security events we successfully extract
parsed_logs = []

# 3. Open and read the log file line by line
with open(log_file_path, "r") as file:
    for line in file:
        # Look only for lines that contain a failed password attempt
        if "Failed password" in line:

            # Chop the sentence into a list of individual words based on spaces
            words = line.split()

            # Grab the month, day, and time
            timestamp = f"{words[0]} {words[1]} {words[2]}"

            # Find the target username and the source IP address
            if "invalid user" in line:
                user = words[words.index("user") + 1]
            else:
                user = words[words.index("for") + 1]

            ip = words[words.index("from") + 1]

            # Package it into a structured security event
            log_entry = {
                "timestamp": timestamp,
                "event": "Failed SSH Login",
                "user": user,
                "source_ip": ip
            }

            # Add it to our list of parsed logs
            parsed_logs.append(log_entry)

# 4. Save the parsed events into a structured JSON file
with open(output_file_path, "w") as outfile:
    json.dump(parsed_logs, outfile, indent=4)

print(f"[+] Success! Parsed {len(parsed_logs)} events and saved to {output_file_path}")

07 // Security Relevance

Failed SSH authentication attempts are useful indicators when investigating unauthorized access and potential brute-force activity. Converting raw authentication logs into structured events makes the data easier for security analysts and automated security tooling to process.

This project demonstrates a simple example of security automation: taking unstructured telemetry, extracting the fields that matter, and preparing the data for downstream analysis or SIEM ingestion.
