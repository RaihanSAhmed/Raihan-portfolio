// PROJECT 01

SSH Log Parser & Security Event Normalizer

A Python automation script designed to parse raw, unstructured Linux SSH authentication logs and normalize them into structured JSON security events.

GitHub Repository ↗ ← Back to Projects

01 // Overview

Security systems frequently ingest large amounts of raw log data. Linux SSH authentication logs contain useful security information, but their unstructured format can make automated analysis more difficult.

This project uses Python to identify failed SSH authentication attempts, extract important fields such as usernames and source IP addresses, and convert the events into structured JSON data.

02 // How It Works

01

Read Logs

Reads the raw SSH authentication log line by line.

02

Filter Events

Searches for failed SSH authentication attempts and filters unrelated log activity.

03

Extract Data

Extracts timestamps, usernames, event types, and source IP addresses.

04

Normalize

Converts the extracted information into structured JSON.
